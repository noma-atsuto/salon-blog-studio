# SALON BLOG STUDIO（デモ版）

ホットペッパービューティーのブログ用アイキャッチ画像を作るための「プロンプト作成ツール」です。
このアプリ自体は画像を作りません。各スタッフが**自分の ChatGPT** に写真を添付し、コピーしたプロンプトを貼り付けて画像を作ります。

## 使い方（スタッフ）
1. 写真を選ぶ（この端末から。写真はどこにも送信・保存されません）
2. 季節（春・夏・秋・冬）とテキストのテイスト（寒色・暖色）を選ぶ
   - 春・秋は暖色、夏・冬は寒色が自動で選ばれます（変更もできます）
   - テイストで、髪色の候補・文字の配色・文章の言葉・プロンプトの色の指示が変わります
3. 投稿者を選ぶ
4. 施術ジャンルを選ぶ
   - カラー（カラー・ダブルカラー・ハイライト）／パーマ（波巻きパーマ・ツイストスパイラル・シャドウパーマ・ニュアンスパーマ）／カット／縮毛矯正（縮毛矯正・曲がる縮毛矯正）／カスタム
5. 髪色を選ぶ（おまかせ・写真のまま・テイストに合う王道カラー）
6. 文章の3案から選ぶ。必要なら直す（「別案を生成」で入れ替え）
7. 完成イメージで配置を確かめる（写真の位置・拡大を調整できます）
8. 「プロンプトをコピー」→ 自分の ChatGPT で写真を添付 → 貼り付けて送信

## メニュー（左のサイドバー。スマホは左上の ☰）
- 作成／履歴／投稿数／スタイル投稿数／管理（スマホは、画面の左側から右へ、または画面中央付近から左へスワイプしても開けます。開いているときに左へスワイプで閉じます）
- スタイル投稿数：共有フォルダ「03_ヘアスタイル作品」の写真の枚数を、スタイル別（下の階層を含めた合計）と投稿者別に、今月・先月・合計で表示します
- 投稿数：「プロンプトをコピー」した回数を、スタッフごとに今月・先月・累計で表示します（この端末の記録のみ）

## スタッフをビューティーメリットから取り込む
1. ビューティーメリットのデータ取得ツール（beauty_merit_report）で、データを取得しておく
2. 次を実行すると、スタッフ名だけを `private/staff.json` に書き出します（売上などは読みません）
   ```bash
   python3 tools/import_beauty_merit.py "（beauty_merit_report のフォルダ）/cache"
   ```
3. 管理画面 →「ビューティーメリットから取り込む」→ そのファイルを選ぶ
- `private/` フォルダは GitHub に上げない設定です。
- 投稿者の初期一覧（`js/data.js` の staff）には、オーナーの判断で現在のスタッフ10名を公開で入れています。一覧から外す人は `private/exclude.txt` に書き、data.js からも消してください。

## 共有フォルダ（Google ドライブ）から写真を選ぶ
スタッフは Google ログイン不要で、合言葉だけで「店舗写真（スタッフ共用）」の写真を選べます。
オーナーのドライブに置いた「配る仕組み」（`gas/Code.gs`）が、オーナーの権限でそのフォルダの中の写真だけを返します。

**オーナーの準備（最初の1回）**
1. https://script.google.com で「新しいプロジェクト」を作り、`gas/Code.gs` の中身を貼り付けて保存（「プロジェクトの設定」でマニフェストを表示し、`gas/appsscript.json` の中身も貼る＝許可を「見るだけ」に限定）
2. 「プロジェクトの設定」→「スクリプト プロパティ」に `PASSCODE` を追加し、合言葉を入れる（合言葉はここにだけ置き、コードや説明書には書かない）
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」→ デプロイ（初回は権限の確認が出ます）
4. 表示された「ウェブアプリのURL」（…/exec）を、このアプリの管理画面「共有画像フォルダ」に入れて保存
5. 「スタッフ配布用の設定ファイルを書き出す」で設定ファイルを作り、合言葉と一緒にスタッフへ個別に渡す

**写真の追加**：共有フォルダでフォルダを開き、「このフォルダに写真を追加」から写真を選びます（利用許可の確認が必要。長い辺2400pxに縮めてJPEGで保存。投稿者と許可の記録は写真の説明欄に残ります。変更・削除はできません）。

**スタッフ**：作成 → 01 写真を選ぶ →「共有フォルダ」を押すだけ（設定ファイル・合言葉は不要。オーナーの判断で、アプリを開いた人はだれでも使える形にしています）

**注意**
- 配る範囲は「店舗写真（スタッフ共用）」の中だけです（フォルダの外のファイルは返しません）。写真の追加はできますが、変更・削除はしません（1枚10MBまで・1時間に60枚まで）。
- 今は合言葉なしのため、アプリを開いた人はだれでも写真を見たり追加したりできます。合言葉を戻すときは、スクリプト プロパティに PASSCODE を入れるだけです（アプリは自動で合言葉の入力欄を出します）。
- お客様の顔が写った写真は、利用の許可があるものだけをフォルダに入れてください。

## 管理画面
- サイドバーの「管理」から開きます。暗証番号は管理者に確認してください（管理画面の「そのほか」で、その端末の番号を変えられます）。
- 編集できるもの：スタッフ一覧（取り込みも可）、カラー候補（カラー・ダブルカラー・ハイライト別、寒色・暖色付き）、キャッチコピー辞書、サブタイトル辞書、共通の禁止事項
- 変更はその端末のブラウザにだけ保存されます（ほかのスタッフの端末には反映されません）。

## パソコンで開く
`index.html` をダブルクリックすると開けます（インターネット接続はフォントの読み込みだけに使います）。

## 公開のしかた（開発者向け）
公開前に `bash tools/bump.sh` を実行して版番号を上げてから、GitHub に送ります。開いている端末には「新しい版があります」と表示されます。

## 動作確認（開発者向け）
```bash
node --test tests/
```

## このデモでまだできないこと（次の段階）
- スタッフ・辞書・履歴をみんなで共有すること（今は端末ごとに保存）
- 本格的なログインと権限管理（今の暗証番号は簡易的なものです）
- AI（API）による文章づくり（今は辞書と組み合わせで作成。API料金はかかりません）
- プロフィール画像の登録

## 注意
- 文章や画像は、公開前に必ず内容を確認してください（誤字・事実と異なる表現・誇大な表現がないか）。
- お客様の写真は、利用の許可をもらったものだけを使ってください。
- GitHub Pages で公開すると、アプリの中身（辞書・プロンプトの型）は誰でも見られます。写真やスタッフ情報はアプリの中に入れないでください。
